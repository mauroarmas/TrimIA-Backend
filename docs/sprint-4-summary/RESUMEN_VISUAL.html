🎯 Historias de Usuario Implementadas

✅ US1 (P1): Confirmar comprobante de pago
Cliente envía imagen de transferencia → cobrador revisa y acepta/rechaza con motivo predefinido → cliente recibe confirmación o solicitud de corrección.
✅ US2 (P1): Recordatorios automáticos
BullMQ scheduler dispara recordatorios 7/3/0 días antes del vencimiento → máx 3 intentos → para cuando cliente avisa pago.
✅ US3 (P2): Verificación de impacto bancario
Cobrador Controlador revisa cuenta bancaria → confirma si pago impactó → cliente recibe confirmación o cobrador responsable recibe alerta.
✅ US4 (P2): Panel del cobrador
KPIs (pendientes, comprobantes, pagos), lista de clientes, historial unificado de eventos (mensajes + notas + eventos).
✅ US5 (P3): Gestión manual
Cobrador resuelve por teléfono → marca cuota como MANUAL → recordatorios se detienen.
